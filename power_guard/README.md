# ⚡ PowerGuard

Dark-themed Flutter battery optimization & hardware telemetry app for Android.

## ✨ Features
- **Live Battery Vitals:** Percentage, charging state, voltage, temperature, and runtime estimates.
- **System Telemetry:** CPU, RAM, and thermal monitoring in a dark UI.
- **Local-First:** Fast offline storage with [Hive](https://docs.hivedb.dev/) and state management via [Riverpod](https://riverpod.dev/).
